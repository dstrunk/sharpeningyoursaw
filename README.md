# Sharpening Your Saw

The website for [Sharpening Your Saw](https://sharpeningyoursaw.com/), built with Jekyll and hosted on GitHub Pages.

## Run locally

```bash
docker compose up jekyll
```

Then open http://localhost:4000/.

## Test

```bash
docker compose run --rm e2e
```

```bash
docker compose run --rm unit
```

Maintenance notes are in [AGENTS.md](AGENTS.md).
